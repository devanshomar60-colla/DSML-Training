# Module 1 - COVID-19 Data Analysis

This module focuses on basic data analysis using Python, Pandas, and Matplotlib.

## Part 1

Topics covered:

- Loading COVID-19 dataset
- Understanding dataset structure
- Checking rows and columns
- `head()` and `tail()`
- Dataset shape and columns
- Statistical summary using `describe()`
- Checking missing values
- Checking duplicate values
- Using `info()`
- Converting Date column to DateTime
- Handling missing values
- Grouping data using `groupby()`
- Calculating Confirmed, Deaths, Recovered and Active cases
- Calculating Death Rate
- Calculating Recovered Rate
- Data visualization using Matplotlib
- Creating bar charts

## Part 2

Topics covered:

- Further COVID-19 data analysis
- Data filtering
- Data transformation
- Statistical analysis
- Data visualization
- Drawing insights from COVID-19 data

## Files

- `Module1_Part1.ipynb` - Part 1 analysis
- `Module1_Part2.ipynb` - Part 2 analysis

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
